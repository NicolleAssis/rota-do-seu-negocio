# A Rota do Seu Negócio — Neo Nexus

Aplicativo web estático, responsivo e independente, pronto para hospedar no GitHub Pages.

## Publicação
1. Crie um repositório GitHub chamado `rota-do-seu-negocio`.
2. Envie o conteúdo desta pasta para a branch `main` na raiz.
3. Abra Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
4. A URL normalmente será `https://SEU-USUARIO.github.io/rota-do-seu-negocio/`.

## Atenção: dados pessoais
O aplicativo não tem backend nem banco de dados. As respostas não são enviadas automaticamente à Neo Nexus. A exportação CSV é local. Antes de divulgação pública ou coleta real de dados pessoais, providencie política/aviso de privacidade, procedimento de consentimento quando aplicável, canal de exercício de direitos e processo seguro de guarda dos arquivos CSV. Não publique CSVs contendo dados de clientes no repositório.

## Métrica
A escala 0–100 km é uma representação ilustrativa da preparação do negócio com base em cinco respostas, não uma estimativa da chance de atingir a meta.
